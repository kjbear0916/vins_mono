# 硬體接線圖指南

## 注意事項

> **重要警告**：ESP32 的 GPIO 多數為 3.3V 邏輯，輸入超過 3.3V 可能損壞晶片！

## 接線總覽

### ESP32-S3-CAM + PIR 感測器

#### PIR (HC-SR501) 接線

| PIR 腳位 | ESP32-S3-CAM | 說明 |
|----------|--------------|------|
| VCC (中間) | 3.3V | 電源正極 |
| GND (左側) | GND | 接地 |
| OUT (右側) | GPIO 13 | 訊號輸出 |

**HC-SR501 連接方式**（面向 PIR 正面，接腳朝下）：
```
正面：    [    感應鏡頭    ]
背面：    VCC   GND   OUT
           |     |     |
          3.3V  GND   GPIO13
```

> **注意**：部分 HC-SR501 模組接腳順序為 GND, OUT, VCC，請以模組標示為準。

#### PIR 靈敏度調整

HC-SR501 上有兩個可變電阻：
- **Sensitivity (Rx)**：調整感應靈敏度，順時針 = 更靈敏
- **Delay Time (Ry)**：調整輸出保持時間（通常 5 秒 - 300 秒）

建議設定：
- 靈敏度：中等（約 50% 位置）
- 延遲時間：最短（5 秒）

#### 跳線設定（工作模式）

HC-SR501 的跳線帽有兩種模式：
- **H (Repeatable)**：重複觸發模式
  - 人持續移動時，會持續輸出高電平
  - **建議使用此模式**
- **L (Non-Repeatable)**：單次觸發模式
  - 只觸發一次，之後固定時間輸出

```

      ┌─────────────────────────┐

      │                         │

      │   GPIO 11 = Y2          │
      │   GPIO 9  = Y3          │
      │   GPIO 8  = Y4          │

      │   GPIO 18 = Y7          │

      │   GPIO 7  = HREF        │

      │  GPIO 22 = IR LED ------│  ← 紅外 LED

```

### 紅外 LED 補光燈接線

建議使用 GPIO 22 控制，連接方式：

```
GPIO 22 ──┬── [330Ω電阻] ── [IR LED] 正極
          │                    │
          │               [IR LED] 負極
          │                    │
          └── GND              GND
```

**串聯多個 LED**（建議最多 3-4 個）：

```
GPIO 22 ──[330Ω]──┬──[LED1]──┬──[LED2]──┬──[LED3]──┐
                  │          │          │          │
                  GND        GND        GND       GND
```

### MicroSD 卡連接（若主控無內建）

若使用 SPI 模式連接外部 SD 卡模組：

| SD 模組 | ESP32-S3 | 說明 |
|---------|----------|------|
| CS | GPIO 4 | 片選 |
| SCK | GPIO 18 | 時脈 |
| MOSI | GPIO 23 | 主出從入 |
| MISO | GPIO 19 | 主入從出 |
| VCC | 5V 或 3.3V | 電源 |
| GND | GND | 接地 |

> **注意**：多數 ESP32-CAM/S3-CAM 主控板上的 SD 卡槽已直接內建連接，無需額外接線。

## 電源接線

### USB 供電（推薦）
```
USB 5V ──[ESP32-CAM 5V/3.3V 輸入]── GND
```

### 鋰電池供電（可選）

```
鋰電池 3.7V(+) ──[TP4056 充電模組]── USB 輸入
                    │
              B+ / B- 連接電池
              OUT+ / OUT- 連接 ESP32 5V / GND
```

### 太陽能供電（進階）

```
太陽能板 ──[CN3065 太陽能充電控制器]── 鋰電池 ── 5V 穩壓 ── ESP32
```

## 檢查清單

接線完成後請逐項確認：

- [ ] PIR 感測器 VCC 連接到 3.3V（不要用 5V！）
- [ ] PIR 感測器 GND 與 ESP32 共地
- [ ] PIR 輸出訊號連接到正確的 GPIO
- [ ] 紅外 LED 有串聯限流電阻（330Ω）
- [ ] 電源正負極正確（反接會燒毀）
- [ ] SD 卡已格式化為 FAT32
- [ ] 所有連接穩固，無鬆動
