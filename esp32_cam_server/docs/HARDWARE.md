## 選購建議

1. **主控板選擇**：
   - 推薦使用 ESP32-S3-CAM，效能較好，支援更高的解析度
   - 若有預算考量，可使用 ESP32-CAM (AI-Thinker)
   
2. **PSRAM 需求**：
   - 使用高解析度（UXGA）需要 8MB PSRAM
   - 如果僅需 QVGA/VGA，可以選擇無 PSRAM 版本

3. **夜間監控**：
   - 必備紅外 LED 補光
   - 考慮使用紅外濾光片切換（IR-cut）模組

4. **電源考量**：
   - 近距離使用：USB 電源最方便
   - 遠端/無線使用：需要鋰電池 + 太陽能板充電

## 實際測試筆記

### 已驗證配置
- **主控**：GOOUUU ESP32-S3-CAM + OV3660
- **WiFi**：iPhone 熱點
- **攝影機設定**：
  - XCLK: 20MHz
  - 解析度: UXGA (1600x1200)
  - 品質: JPEG 10
  - PSRAM: 已啟用
- **效能**：QIGA 解析度下約 15-20 FPS

### 注意事項
1. 確保 ESP32 與 PIR 感測器共用電源地線
2. 紅外 LED 使用時需注意散熱
3. 戶外使用需要防水外殼
4. MicroSD 卡建議使用 FAT32 格式
